## Common Patterns and Guidelines

### Documentation Style
- Use markdown format with GitHub-flavored syntax
- Include code blocks with appropriate language tags (yaml, bash, etc.)
- Provide troubleshooting sections with common issues and solutions
- Cross-reference related documents
- Use ASCII diagrams for network architecture where helpful
- Include verification commands for all configurations

### Network Information Format
- Always specify VLAN in IP references: "10.0.20.100 (VLAN 20)"
- Use consistent terminology: "Management VLAN" not "VLAN 1" unless in tables
- Include gateway and DNS for each subnet
- Document firewall rules with source → destination format

### Configuration Examples
- Include both web UI steps and CLI configuration
- Provide verification commands after configuration changes
- Use placeholders like `[PASSWORD]`, `<truenas-ip>`, `<namespace>` for sensitive/variable data
- Comment configuration files clearly

### File Naming
- Use underscores for multi-word files: `Network_Configuration.md`
- Use consistent capitalization
- Hidden files for metadata: `.claude-init.md`

## Quick Commands Reference

### OKD Cluster Management
```bash
# Login to cluster
oc login https://api.okd.claffey.cloud:6443

# Check cluster status
oc get nodes
oc get co  # Cluster operators

# Access nodes via SSH
ssh core@10.0.20.100  # K81
ssh core@10.0.20.101  # K82
ssh core@10.0.20.102  # K83
```

### Network Testing
```bash
# From OKD node - test connectivity
ping 10.0.20.1      # Gateway
ping 10.0.20.2      # DNS
dig api.okd.claffey.cloud
curl -k https://api.okd.claffey.cloud:6443/healthz

# Test storage network
ping 10.0.30.x      # TrueNAS storage IP
showmount -e 10.0.30.x  # NFS exports
```

### OpenWRT Access Points
```bash
# SSH to access points
ssh root@10.0.1.21  # AP1
ssh root@10.0.1.22  # AP2

# Reload wireless
wifi reload

# Check wireless status
iwinfo

# Network restart
/etc/init.d/network restart
```
