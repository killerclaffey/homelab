## How to Get Required Information

### Get MAC Addresses:
# Run on each node:
#   ip link show
# Look for the "link/ether" line for your primary interface
# Example output:
#   2: enp1s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
#      link/ether 52:54:00:6b:8c:8e brd ff:ff:ff:ff:ff:ff

### Get Interface Name:
# Run on each node:
#   ip link show
# The interface name is before the colon (e.g., enp1s0, ens3, eth0)

### Generate SSH Key:
#   ssh-keygen -t rsa -b 4096 -C "okd-cluster-access"
#   cat ~/.ssh/id_rsa.pub

### Verify DNS:
#   nslookup api.okd.claffey.cloud
#   nslookup k81.okd.claffey.cloud
#   nslookup 10.0.20.100

## Installation Commands Reference

### 1. Prepare Configuration:
#   vim install-config.yaml  # Update SSH_PUBLIC_KEY
#   vim agent-config.yaml    # Update MAC addresses and interface names

### 2. Generate ISO:
#   openshift-install agent create image

### 3. Boot Nodes (IN ORDER):
#   1. Boot k81 (10.0.20.100) - Wait 5-10 minutes
#   2. Boot k82 (10.0.20.101)
#   3. Boot k83 (10.0.20.102)

### 4. Monitor Installation:
#   openshift-install agent wait-for bootstrap-complete --log-level=info
#   openshift-install agent wait-for install-complete --log-level=info

### 5. Access Cluster:
#   export KUBECONFIG=$PWD/auth/kubeconfig
#   oc get nodes

## Validation Checklist

Before generating ISO, verify:
- [ ] All MAC addresses are correct and unique
- [ ] SSH public key is correct
- [ ] Interface names match your hardware
- [ ] DNS records are created and resolving
- [ ] All IPs are in the same subnet as gateway
- [ ] Gateway and DNS server are reachable from all nodes
- [ ] Nodes have internet access
- [ ] Firewall rules allow traffic between nodes

## Expected Timeline

- ISO Generation: 2-5 minutes
- Bootstrap Phase: 15-30 minutes
- Installation Complete: 30-45 minutes
- Total Time: ~60-90 minutes

## Important Notes

1. The first node booted (k81 - 10.0.20.100) becomes the rendezvous host
2. All other nodes will contact the rendezvous host to join the cluster
3. The same ISO can be used for all nodes
4. Nodes must have internet access to pull container images
5. DNS must be working correctly before starting installation
6. Once a node is booted with the ISO, don't interrupt it - let it complete
